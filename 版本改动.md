# 版本改动

## 新增内容

- 新增「收纳箱」道具与完整流程：两点框选建筑 → 收录方块、方块实体与生物 → 原地清空 → 未落地前可潜行右键复原回原位。
- Added the "Storage Case" item with the full flow: pick two corners, collect blocks, block entities and mobs, clear the source, then sneak + right click to restore in place while unplaced.

- 新增预览与落地：已收纳箱右键在落点开预览，可左右旋转 90°、上下微调；落点有方块挡路时标出冲突并拒绝确认；确认后建筑（含方块、方块实体、生物）落到新位置。
- 预览带按键与视角反馈：R 键旋转（按住 Shift 反向）、PageUp/PageDown 上下微调、V 键隐藏预览；挡路的格子显示为红色线框，状态栏实时报体积、朝向与冲突数。
- 选区改成「水平两点＋↑/↓ 加高」：左键点两个水平角，底面就在点到的方块上，↑/↓ 直接加高、降低；选区实时显示包围盒描边，HUD 报出体积与格数。
- 放置预览改为跟着准星走：右键开预览后预览随手看的位置移动，左键落地、右键取消、←/→ 转向、↑/↓ 上下微调、中键冻结位置、V 隐藏。
- 挡路提示改成准星下的清单：最多列 4 个挡路方块的名字与坐标，其余只报数量。
- 收录前先弹确认小窗：列出体积、方块数、方块实体数、随行实体数，以及「留下不动」清单（玩家、模组实体、非生物、骑乘或临时实体）；确认后才清空原地，取消或按 Esc 则建筑原封不动。
- Added preview and placement: right click a filled case to preview at the clicked spot, rotate in 90° steps, nudge vertically, see conflicts block the confirm, and land the building — blocks, block entities and mobs included.
- Added preview controls and feedback: R turns it (shift turns back), PageUp/PageDown nudge it, V hides it; blocked cells show as red outlines and the status line reports size, facing and conflict count.
- The selection is now a horizontal area plus a height: left click two ground corners, then up/down raise and lower the box from the floor they were picked on, with a live box outline and a size readout under the crosshair.
- The placement ghost now follows the crosshair: after right click opens it, left click lands it, right click cancels, left/right arrows turn it, up/down nudges it, the middle button freezes the spot and V hides it.
- Blocking blocks are now listed under the crosshair: up to four names with coordinates, then just a count.
- A confirmation window now opens before collecting: size, block count, block entities, travelling entities and the "left behind" list (players, mod entities, non-living, ridden or transient); the spot is only cleared on confirm, while cancel or Esc leaves the building untouched.

- 放置预览改用真方块半透明模型：预览里的方块就是它们本来的样子（半透明、挡路的格子染红），体积过大或烘焙过慢时退回线框并在准星下说明。
- 收录确认小窗的「建筑名称」改成输入框：可以直接起名（回车即确认，最多 48 字），名字跟着收纳箱保存；留空则保留自动生成的名字。
- 挡路提示压缩成一眼能读的一行：先报格数，再列最多三种挡路方块与数量，最后给首个挡路坐标；逐个名字与坐标仍列在准星下方。
- The placement ghost now uses the real block models, drawn translucent with blocked cells tinted red; oversized or slow-to-bake previews fall back to the outline with a note under the crosshair.
- The capture window's name line is now an input box: type a name (Enter confirms, 48 characters max) and it is saved with the case; leaving it empty keeps the generated name.
- The blocking message is now one quick line — the count first, then up to three block types with counts, then the first blocked coordinate; the per-block names and coordinates stay listed under the crosshair.

- 修掉两条会「凭空多出一栋建筑」的路子：预览中滚动快捷栏或按 R 换手后落地，收纳箱不再漏解绑；落地还没结束的那几帧里也不能再发起复原（会提示「上一栋还在搬运」）。
- Two paths that could leave a second copy of a building behind are closed: scrolling the hotbar (or pressing R, which also swaps hands) between opening the preview and landing no longer leaves the case bound, and a restore is refused while the landing is still in the air.

- 收录与落地改成「一次只搬一件」：清点、落地或复原还没结束时再点收录／复原会被拒绝（提示稍等），避免第二次收录把收纳箱里的蓝图静默换成一份空档。
- A move is now one at a time per player: collecting, landing or restoring again while the previous one is still running is refused, so a second collect can no longer quietly replace the case's blueprint with an empty capture.

- 选区改成一次点击只记一个角：第一次记第一个角，第二次记第二个角；两个角都定好后，再点别处只替换第二个角，左键点已选中的角就取消该角（选位减一），准星下同时报出「已选 1/2 角」。
- 落地预览也能平移：按住 Shift + 方向键把整栋建筑沿地面挪一格（↑/↓ 沿 Z、←/→ 沿 X），平移时会自动冻住，按中键解冻即可重新跟准星。
- The placement preview can be slid too: hold shift and press an arrow key to walk the whole building one block across the ground (up/down along Z, left/right along X); it freezes as it moves, and the middle button lets it follow the crosshair again.

- 收纳后的建筑各自一个 .hsm 文件，落在世界目录的 homestead_mover/blueprints/：拷到别的设备或别的存档照样能完整复原；旧版单文件存储会在首次启动时自动拆成一栋一个，旧文件留成 .migrated 备份。
- 空收纳箱按 I 打开导入页：列出这个世界里的 .hsm 文件（名字、体积、大小），点一行就装进箱子，右键即可预览落地。
- 选位时按住 Shift + 方向键平移整个选区：↑/↓ 沿 Z 走、←/→ 沿 X 走，弧度和高度都不变；松开 Shift 仍是原方向键加高。
- Each collected building now lives in its own .hsm file under the world folder's homestead_mover/blueprints/: copy it to another machine or save and it restores whole. The old single-file store is split into one file per building on first load, with the old file kept as .migrated.
- An empty case opens an import page on I: it lists the .hsm files of this world (name, size, bytes) and one click loads a building into the case.
- Holding shift while measuring slides the whole selection: up/down along Z, left/right along X, keeping the shape and the height; without shift the arrow keys still raise it.

- 选中的角各自有一个绿色方块描边：一个角也能一眼看见框在哪，蓝框仍是两个角合起来的选区。
- Picked corners now get their own green cube outline — one corner is already visible on its own, while the blue box still marks the finished area.

- The selection now takes exactly one corner per click: the first click stands a corner, the second closes the area, later clicks only move the second corner, and clicking a corner that is already picked drops it (one corner fewer) with "1 of 2 corners picked" under the crosshair.

## Bug 修复

- 清空源区域前先清空容器内容，避免移除箱子方块时把里面的物品弹成掉落物（重复刷物品）。
- 大体积采集的收尾「打包」阶段改为分帧切片：10 万格建筑不再卡单 tick 三十余毫秒（实测典型 tick 3.0ms）。
- Container contents are now emptied before their block is removed, so clearing a source chest no longer ejects its items as duplicate drops.
- The closing pack-up step of a large collection is now sliced across ticks: a 100k-cell building no longer stalls a single tick for thirty-odd milliseconds (measured typical tick 3.0 ms).

- 修掉预览平移第一下「先上下跳、再横着走」：平移前先把客户端准星下的真实位置同步给服务端（服务端原来还拿着开预览时那份旧原点），并改用键盘即时状态判断 Shift，同一下不会再被当成上下微调。
- Fixed the first shift-slide jumping up or down before moving sideways: the ghost's real position is handed to the server before sliding (it was still holding the origin from when the preview opened), and Shift is read from the live key state so the same press is never taken as a vertical nudge.

- 修掉「左键选水平范围只能选中一个格子、体积永远 1x1x1」：手里拿着收纳箱时左键不再走原版挖掘（收纳箱的标签一变，客户端就每 tick 重发一次挖掘包，一次点击被记成两个重合的角），现在一次点击只记一个角。
- 收起收纳箱（换成别的物品）后，选区描边和准星下的选区文字不再残留，只在手里拿着收纳箱时显示。
- Fixed "a left click can only pick one cell and the area is always 1x1x1": with the case in hand the click no longer goes through vanilla mining (every tag change made the client re-send the mining packet each tick, so one click recorded two corners on the same block); one click now records exactly one corner.
- Putting the case away no longer leaves the selection outline or the crosshair text behind: both only show while the case is in hand.
